Chọn nhiều file .bytes
Có thể chọn hoặc kéo nhiều file vào đây. File trùng tên vẫn được giữ nguyên.
Thứ tự gộp: file 1 → file 2 → ... → file cuối
Tool giữ nguyên từng byte và nối dữ liệu theo đúng thứ tự đã chọn.
Lưu ý: nối 2 file nhị phân không tự biến chúng thành một package game hợp lệ. Nếu định dạng .bytes của game có bảng index, header, offset, checksum hoặc cấu trúc AssetBundle riêng thì cần parser/packer đúng định dạng thay vì chỉ nối byte. Tool này là bộ gộp nhị phân tổng quát và không phá mã hóa/chữ ký/bảo vệ của game.
